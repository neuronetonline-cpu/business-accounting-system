# POS Import

The POS Import Center supports the current EASY POS monthly Sales Report PDF format used in testing.

## Opening position
- Set the opening date.
- Import the opening stock Excel report.
- Enter cash and bank balances.
- Customer receivables, supplier payables, other assets and other liabilities are optional and can be added later.
- The opening entry is balanced automatically through the historical/opening equity account.

## POS sales
- Select the EASY POS Sales Report PDF.
- Preview bills before posting.
- Products are matched against the product master created/imported from the opening stock file.
- Bill numbers are checked against existing sales to prevent duplicate imports.
- Payment types map to Cash, selected Bank, Card Receipts, COD Receivable, or Customer Receivable.
- POS final bill totals are posted as revenue; POS item costs are used for COGS and inventory reduction.
